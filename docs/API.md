# API reference

The app is a plain JSON API plus one HTML page. Interactive docs are generated by FastAPI at `/docs` (Swagger) and `/redoc`.

If `APP_PASSWORD` is set, log in first with `POST /login` (form field `password`) and keep the `osint_session` cookie. Without a valid cookie, `/api/*` returns `401 {"detail": "login required"}`. Too many requests return `429`.

Target types: `username`, `email`, `domain`, `ip`, `phone`, `url`, `crypto`, `company`.

## Health and config

| Method and path | Description |
|---|---|
| `GET /api/health` | `{"ok": true, "tools": 1165}`. Never needs login. |
| `GET /api/config` | Which API keys are configured (true/false only, never the keys), whether login is on, the list of encoder operations and target types. |

## Catalog

`GET /api/categories` returns `[{"name": "Username", "count": 19}, ...]`.

`GET /api/tools` query parameters:

| Parameter | Meaning |
|---|---|
| `q` | Text to find in name, description or path |
| `category` | Exact category name |
| `pricing` | `free`, `freemium` or `paid` |
| `flag` | `api`, `local` or `dork` |
| `limit` | Page size, default 60, maximum 2000 |
| `offset` | Start position |

Response: `{"total": 123, "items": [{"id", "name", "url", "description", "category", "path", "pricing", "opsec", "local", "api", "dork", "registration", "deprecated", "status"}]}`.

## Investigations

Request body (both endpoints):

```json
{ "value": "example.com", "type": "domain", "region": "BD", "limit": 200 }
```

Only `value` is required. `type` is detected if omitted. `region` is used for phone numbers without a country code. `limit` (1 to 700) is how many sites a username sweep checks.

### `POST /api/investigate`

Runs the lookup and waits for the result. Simple, but the request stays open for as long as the lookup takes.

### `POST /api/jobs` and `GET /api/jobs/{id}`

Starts the lookup in the background and returns `{"id": "..."}`. Poll the job:

```json
{ "status": "running", "progress": {"checked": 40, "total": 200}, "type": "username", "value": "octocat" }
```

`status` is `running`, `done` or `error`. When `done`, the response has `result`; when `error`, it has `error`.

### Result shape

```json
{
  "type": "domain",
  "value": "example.com",
  "cached": false,
  "lookup": { "...type specific..." },
  "tools": [ "...catalog entries relevant to this type..." ],
  "tool_categories": ["Domain Name", "Cloud Infrastructure", "..."]
}
```

Validation errors return `400 {"detail": "..."}`, for example an invalid IP, an email without `@`, or a username with illegal characters.

### `lookup` by type

| Type | Main keys |
|---|---|
| `domain` | `dns`, `rdap`, `subdomains_crtsh`, `wayback`, `virustotal` |
| `ip` | `geo`, `network`, `rdap`, `reverse_dns`, `shodan`, `abuseipdb`, `virustotal` |
| `email` | `domain`, `mx`, `has_mx`, `spf`, `gravatar_profile_exists`, `breaches` |
| `username` | `sites_checked`, `sites_total`, `found` (list of `{site, category, url}`) |
| `phone` | `valid`, `possible`, `e164`, `international`, `country_code`, `region`, `location`, `line_type`, `original_carrier`, `timezones` |
| `crypto` | `chain`, balance, transaction counts, `explorer` |
| `url` | `final_url`, `status`, `redirect_chain`, `title`, `headers`, `wayback` |
| `company` | `gleif_legal_entities`, `sec_edgar_matches`, `search_links` |

A section that needs a missing API key contains `{"info": "set ... to enable"}`.

## Cases

| Method and path | Body | Description |
|---|---|---|
| `GET /api/cases` | | List cases with item counts |
| `POST /api/cases` | `{"name": "..."}` | Create a case (name up to 120 characters) |
| `GET /api/cases/{id}` | | Case with all items and their results |
| `DELETE /api/cases/{id}` | | Delete a case and its items |
| `POST /api/cases/{id}/items` | `{"kind", "value", "result", "note"?}` | Save a result into a case |
| `PATCH /api/items/{id}` | `{"note": "..."}` | Edit an item's note |
| `DELETE /api/items/{id}` | | Remove an item |
| `GET /api/cases/{id}/export?format=md\|json\|html` | | Download a report. The HTML version is meant for print to PDF. |

## Toolbox

| Method and path | Description |
|---|---|
| `POST /api/toolbox/encode` | Body `{"op": "base64-encode", "text": "hello"}` returns `{"result": "aGVsbG8="}`. Operations: `base64-encode/decode`, `hex-encode/decode`, `url-encode/decode`, `html-encode/decode`, `binary-encode/decode`, `rot13`, `md5`, `sha1`, `sha256`, `sha512`, `identify-hash`. |
| `GET /api/toolbox/dorks?target=example.com&type=` | Google dork queries with ready-made Google, DuckDuckGo and Bing links. |
| `POST /api/toolbox/exif` | Multipart upload, field `file`, up to 15 MB. Returns tags and, if present, GPS coordinates with a map link. |

## Example with curl

```bash
curl -s -X POST http://127.0.0.1:8000/api/investigate \
  -H "Content-Type: application/json" \
  -d '{"value": "+8801712345678"}'
```
