# OSINT Hub (বাংলা)

**[OSINT Framework](https://osintframework.com/)-এর সব টুল এক জায়গায়, সাথে বিল্ট-ইন লুকআপ, কেস সেভ এবং টুলবক্স। পুরোটা একটাই Python ওয়েব অ্যাপ, নিজের সার্ভারে চালানো যায়।**

## OSINT কী?

OSINT মানে **Open Source Intelligence**, অর্থাৎ সবার জন্য খোলা তথ্য থেকে তথ্য খুঁজে বের করা ও বিশ্লেষণ করা। যেমন ডোমেইনের DNS রেকর্ড, ডোমেইন রেজিস্ট্রেশনের তথ্য, পাবলিক প্রোফাইল, কোম্পানির রেজিস্ট্রি, ব্লকচেইন এক্সপ্লোরার, আর্কাইভ করা ওয়েবপেজ। সাইবার সিকিউরিটি টিম, সাংবাদিক, জালিয়াতি তদন্তকারী আর গবেষকরা প্রতিদিন এটা ব্যবহার করেন।

OSINT Framework একটা জনপ্রিয় ডিরেক্টরি, যেখানে এক হাজারের বেশি OSINT টুলের লিংক আছে। কিন্তু শুধু লিংকের তালিকা থাকলে প্রতিটা সাইট আলাদা করে খুলে বারবার একই টার্গেট টাইপ করতে হয়, আর নোট রাখতে হয় অন্য কোথাও।

**OSINT Hub এই সমস্যা মেটায়।** আপনি একবার একটা টার্গেট দেন (ডোমেইন, IP, ইমেইল, username, ফোন নম্বর, URL, ক্রিপ্টো ঠিকানা বা কোম্পানির নাম)। অ্যাপ নিজে বুঝে নেয় সেটা কী ধরনের, যা যা লুকআপ নিজে চালাতে পারে তা চালায়, ফলাফল দেখায়, ওই টাইপের জন্য প্রাসঙ্গিক সব টুলের তালিকা দেয়, আর সবকিছু একটা কেসে সেভ করে রিপোর্ট হিসেবে এক্সপোর্ট করতে দেয়।

## ফিচার

- **ক্যাটালগ:** ৩৩টা ক্যাটাগরিতে ১১৬৫টা টুল। সার্চ করা যায়, আর ক্যাটাগরি, দাম (ফ্রি/ফ্রিমিয়াম/পেইড), API আছে কি না, লোকাল ইনস্টল, Google dork দিয়ে ফিল্টার করা যায়।
- **অনুসন্ধান (Investigate):** একটা ইনপুট বক্স, টার্গেটের ধরন নিজে থেকে চেনা, ব্যাকগ্রাউন্ডে চলা জব (প্রগ্রেস সহ), ১৫ মিনিটের ক্যাশ।
- **পিভট:** ফলাফলের যেকোনো IP, ডোমেইন বা ইমেইলে ক্লিক করলে সেটা নিয়ে নতুন অনুসন্ধান শুরু হয়। এন্টিটি গ্রাফে দেখা যায় ফলাফলটা কীসের সাথে যুক্ত।
- **কেস:** ফলাফল কেসে সেভ (SQLite), নোট যোগ, Markdown/JSON/প্রিন্টযোগ্য HTML রিপোর্ট এক্সপোর্ট (PDF হিসেবে সেভ করা যায়)।
- **টুলবক্স:** ১৬টা encode/decode/hash অপারেশন, হ্যাশ শনাক্তকারী, Google dork জেনারেটর, আপলোড করা ছবির EXIF ও GPS রিডার।
- **নিরাপত্তা:** ঐচ্ছিক পাসওয়ার্ড লগইন, প্রতি IP-তে রেট লিমিট, URL ফেচে SSRF সুরক্ষা, ইনপুট যাচাই।
- **ব্যবহারযোগ্যতা:** ডার্ক ও লাইট থিম, ইংরেজি ও বাংলা লেবেল, মোবাইলে কাজ করে।

### বিল্ট-ইন লুকআপ

| টার্গেট | কী দেখায় | API key লাগে? |
|---|---|---|
| ডোমেইন | DNS রেকর্ড, RDAP/WHOIS, সাবডোমেইন (crt.sh), Wayback স্ন্যাপশট | শুধু VirusTotal অংশে |
| IP | লোকেশন, ASN, RDAP, reverse DNS | শুধু Shodan/AbuseIPDB/VirusTotal অংশে |
| ইমেইল | ডোমেইনের MX/SPF, Gravatar আছে কি না, ব্রিচের নাম | ব্রিচের জন্য Have I Been Pwned |
| Username | ৭০০টা পর্যন্ত পাবলিক সাইটে আছে কি না (WhatsMyName) | না |
| ফোন নম্বর | বৈধতা, দেশ, লাইন টাইপ, আসল ক্যারিয়ার, টাইমজোন (অফলাইন, শুধু নম্বর বিশ্লেষণ) | না |
| ক্রিপ্টো ঠিকানা | Bitcoin/Ethereum ব্যালেন্স ও ট্রানজ্যাকশন সংখ্যা | না |
| URL | রিডাইরেক্ট চেইন, হেডার, টাইটেল, Wayback (শুধু পাবলিক হোস্ট) | না |
| কোম্পানি | GLEIF ও SEC EDGAR থেকে তথ্য | না |

যেসব অংশে key লাগে, key না দেওয়া পর্যন্ত সেখানে পরিষ্কার লেখা থাকে কী সেট করতে হবে। কিছু লুকানো বা বানানো হয় না।

## দ্রুত শুরু

Python 3.10 বা তার নতুন ভার্সন লাগবে।

```bash
git clone https://github.com/nextcorebdofficial/osint-hub.git
cd osint-hub
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python -m uvicorn main:app --reload
```

তারপর <http://127.0.0.1:8000> খুলুন। API ডকুমেন্টেশন পাবেন <http://127.0.0.1:8000/docs> এ।

Docker দিয়ে চালাতে চাইলে `.env.example` কপি করে `.env` বানান (অন্তত `APP_PASSWORD` দিন), তারপর `docker compose up --build`।

## ব্যবহারের নিয়ম

1. উপরের বক্সে টার্গেট লিখুন, যেমন `example.com`, `8.8.8.8`, `someone@example.com`, `octocat`, `+14155552671`।
2. টাইপ **auto-detect** রেখে দিন, বা নিজে বেছে নিন (কোম্পানির নামের জন্য কাজে লাগে)।
3. **অনুসন্ধান** চাপুন। ধীর লুকআপে প্রগ্রেস দেখা যায়।
4. ফলাফল পড়ুন। কোনো চিপ বা গ্রাফ নোডে ক্লিক করলে সেটা নিয়ে পিভট হয়।
5. একটা কেস বেছে **Save to case** চাপুন। কেস বানাতে **কেস** ট্যাবে যান।
6. **কেস** ট্যাবে কেস খুলে নোট লিখুন ও রিপোর্ট এক্সপোর্ট করুন।

ফোন নম্বরে দেশের কোড দিন (`+880...`)। না দিলে টাইপ সিলেক্টরের পাশের ছোট বক্সে দেশের কোড লিখুন (যেমন `BD`)।

## দায়িত্বশীল ব্যবহার

OSINT শুধু পাবলিক তথ্য ব্যবহার করে, কিন্তু পাবলিক মানেই নিরীহ নয়। এই তথ্য দিয়ে মানুষকে হয়রানি, স্টকিং বা প্রতারণা করা যায়। ব্যবহার বা ডিপ্লয় করার আগে [docs/ETHICS_AND_LEGAL.md](docs/ETHICS_AND_LEGAL.md) পড়ুন।

ইচ্ছা করে যা রাখা হয়নি:

- **মুখ শনাক্তকরণ সার্চ ইঞ্জিন নেই।** FaceCheck, PimEyes, Lenso, FaceSeek ডেটাসেট ও আপডেটার থেকে বাদ, কারণ এগুলো অনুমতি ছাড়া ছবি দেখে অপরিচিত মানুষ শনাক্ত করে।
- **ফোন লুকআপ শুধু নম্বর বিশ্লেষণ করে।** নম্বরের মালিক কে, তা বলে না।
- **URL ফেচ প্রাইভেট ঠিকানা ব্লক করে**, যাতে পাবলিক সার্ভার দিয়ে আপনার অভ্যন্তরীণ নেটওয়ার্কে খোঁচানো না যায়।
- **অন্যরা পৌঁছাতে পারে এমন যেকোনো সার্ভারে পাসওয়ার্ড দিন।**

শুধু আইনসম্মতভাবে, আর যাদের তদন্ত করার অধিকার আপনার আছে তাদের ক্ষেত্রে ব্যবহার করুন।

## জানা সীমাবদ্ধতা

- জব আর ক্যাশ মেমরিতে থাকে, রিস্টার্ট দিলে হারায়। কেস স্থায়ীভাবে সেভ থাকে।
- সবার জন্য একটাই পাসওয়ার্ড, আলাদা ইউজার অ্যাকাউন্ট নেই।
- Username সোয়েপে ভুল পজিটিভ/নেগেটিভ আসতে পারে। ফলাফলকে সূত্র হিসেবে ধরে নিজে যাচাই করুন।
- ১১৬৫টা টুলের বেশিরভাগই বাইরের সাইটের লিংক, এই অ্যাপের ভেতরে চলা ফিচার নয়।
